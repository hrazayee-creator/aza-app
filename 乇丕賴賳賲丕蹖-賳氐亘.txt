نسخه ۱۱: مدیریت کالا (ویرایش/حذف)، حذف فاکتور، نمودار حرفه‌ای بدهی‌ها و پشتیبان‌گیری/بازیابی در تنظیمات.

AZA PWA — نسخه آفلاین ۳

تغییرات نسخه ۶:
- اسکن دوربین با تلاش مجدد برای بازکردن دوربین و پیام خطای دقیق‌تر. دوربین فقط در HTTPS و پس از دادن مجوز مرورگر باز می‌شود.
- فیلد ورود دستی بارکد زیر دکمه اسکن دوربین در صفحه فروش.
- فاکتور حرفه‌ای با شماره‌گذاری از ۱، تاریخ و ساعت، نام فروشگاه در سربرگ، و آدرس و موبایل در پایین.
- گزینه ذخیره ورود، دکمه خروج، و بخش کشویی تغییر نام کاربری و رمز عبور.

محتویات بسته:
- index.html: برنامه AZA
- manifest.json: مشخصات نصب PWA
- service-worker.js: اجرای آفلاین و دریافت نسخه‌های جدید
- icons/: آیکون‌های برنامه
- .github/workflows/deploy.yml: انتشار خودکار روی GitHub Pages
- README_FA.md: راهنمای فارسی انتشار

انتشار روی GitHub:
1) یک مخزن جدید بساز و آن را Public قرار بده.
2) فایل‌های داخل این ZIP را مستقیماً در ریشه مخزن قرار بده؛ پوشه اضافی aza_pwa نساز و پوشه .github را هم نگه دار.
3) از Settings > Pages، گزینه Build and deployment را روی GitHub Actions قرار بده.
4) به Actions برو و موفقیت workflow با نام Deploy AZA PWA را بررسی کن.
5) لینک GitHub Pages را با Chrome گوشی باز کن و از منوی مرورگر گزینه Install app یا Add to Home screen را انتخاب کن.

ذخیره‌سازی:
- داده‌های اصلی برنامه در IndexedDB ذخیره می‌شوند و از کش فایل‌های برنامه جدا هستند.
- اگر قبلاً داده‌ای در localStorage همین نسخه وجود داشته باشد، در اولین اجرا به IndexedDB منتقل می‌شود.
- پاک‌کردن کش عادی مرورگر معمولاً IndexedDB را حذف نمی‌کند؛ پاک‌کردن کامل داده‌های سایت/مرورگر یا حذف داده‌های برنامه می‌تواند اطلاعات را پاک کند.
- قبل از استفاده واقعی، از بخش پشتیبان‌گیری برنامه یک فایل JSON تهیه و در جای امن نگهداری کن.

به‌روزرسانی:
- نسخه جدید را در همان مخزن GitHub جایگزین کن و commit انجام بده.
- پس از موفقیت workflow، همان لینک Pages را برای مشتری بفرست. با بازکردن لینک در حالت آنلاین نسخه تازه دریافت می‌شود؛ اگر برنامه از قبل باز باشد، بنر «نسخه جدید AZA آماده است» امکان بارگذاری مجدد را می‌دهد.
- داده‌های فروشگاه در سرور ذخیره نمی‌شوند و با انتشار فایل‌های جدید عمداً پاک نمی‌شوند.

توجه درباره مبنای نسخه:
این بسته بر اساس آخرین فایل HTML قابل خواندن در آرشیو فعلی ساخته شده است. ZIP اندرویدی مورخ ۱۴ اکتبر در آرشیو قابل استخراج نبود؛ بنابراین این بسته را نباید بدون مقایسه، نسخه دقیق همان ZIP دانست.

پیش از استفاده واقعی با داده آزمایشی، ثبت کالا و فاکتور، بستن و بازکردن برنامه، حالت پرواز، پشتیبان‌گیری و بازیابی را آزمایش کن.

قابلیت‌های نسخه جدید:
- در بخش فروش جدید، دکمه «اسکن بارکد» دوربین گوشی را باز می‌کند. در مرورگر سازگار، بارکد را می‌خواند و کالا را به سبد اضافه می‌کند. اجازه دوربین لازم است و نشانی برنامه باید HTTPS باشد. اگر اسکن خودکار پشتیبانی نشود، بارکد را دستی در همان پنجره وارد کنید.
- تصویر فاکتور ارسالی مرتب شده: مشخصات کالا سمت راست و مبلغ سمت چپ قرار می‌گیرد و جمع‌ها ردیفی نمایش داده می‌شوند.


اصلاحات نسخه ۶:
- نام برنامه فقط «AZA» است.
- هر لیبل چاپی بارکد متفاوت و قابل‌اسکن خودش را دارد؛ برای بارکد عددی، شماره‌گذاری افزایشی انجام می‌شود.
- فاکتور خروجی با محتوای نزدیک‌تر به مرکز، سربرگ فروشگاه، شماره/تاریخ/ساعت مرتب و ردیف‌های منظم بازطراحی شده است.
- مبلغ دریافتی به‌صورت پیش‌فرض با مبلغ قابل پرداخت محاسبه می‌شود و پس از تخفیف به‌روزرسانی می‌شود؛ در صورت نیاز همچنان می‌توان مبلغ دریافتی را دستی تغییر داد.
- متن گزینه ورود کوتاه‌تر شده است: «ذخیره نام کاربری و رمز عبور».

اصلاح نسخه ۶: طراحی پیش‌نمایش فاکتور برای چاپ و ذخیره PDF هم استفاده می‌شود؛ ذخیره تصویر و اشتراک‌گذاری نیز بر اساس همان HTML/CSS فاکتور است.
