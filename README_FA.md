# راهنمای انتشار AZA PWA — نسخه ۶

## محتویات
- `index.html`: نسخه وب فعلی AZA
- `manifest.json`: مشخصات نصب PWA
- `service-worker.js`: اجرای آفلاین و دریافت نسخه‌های جدید
- `icons/`: آیکون‌های برنامه
- `.github/workflows/deploy.yml`: انتشار خودکار روی GitHub Pages

## تغییرات نسخه ۶
- بازکردن دوربین با تلاش مجدد برای دوربین پیش‌فرض و پیام خطای مشخص‌تر؛ نیازمند HTTPS و اجازه دوربین است.
- ورودی دستی بارکد زیر دکمه دوربین در صفحه فروش قرار دارد.
- قالب فاکتور حرفه‌ای‌تر، شماره‌گذاری از ۱، تاریخ و ساعت، و نمایش آدرس و موبایل فروشگاه.
- ذخیره نام کاربری و رمز عبور با گزینه اختیاری در صفحه ورود، دکمه خروج، و تنظیمات امنیتی کشویی.

## انتشار روی GitHub Pages
1. یک مخزن GitHub جدید بساز و آن را `Public` قرار بده.
2. محتویات این بسته را مستقیماً در ریشه مخزن آپلود کن؛ پوشه اضافی `aza_pwa` نساز و پوشه مخفی `.github` را هم حفظ کن.
3. در مخزن به `Settings → Pages` برو و گزینه `Build and deployment` را روی `GitHub Actions` قرار بده.
4. به تب `Actions` برو و موفقیت workflow با نام `Deploy AZA PWA` را بررسی کن.
5. آدرس GitHub Pages را در Chrome گوشی باز کن و از منوی مرورگر `Install app` یا `Add to Home screen` را انتخاب کن.

## ذخیره‌سازی و حریم داده
- داده‌های اصلی برنامه در `IndexedDB` ذخیره می‌شوند و از کش فایل‌های برنامه جدا هستند.
- اگر داده‌های نسخه قدیمی در `localStorage` همین برنامه وجود داشته باشند، در اولین اجرا به `IndexedDB` منتقل می‌شوند.
- پاک‌کردن کش عادی مرورگر معمولاً `IndexedDB` را حذف نمی‌کند؛ اما پاک‌کردن کامل داده‌های سایت/مرورگر، حذف داده‌های برنامه یا از دست رفتن گوشی می‌تواند اطلاعات را از بین ببرد.
- از بخش پشتیبان‌گیری برنامه، مرتب فایل JSON بگیر و آن را خارج از گوشی نگه دار. برنامه اطلاعات فروشگاه را به سرور ارسال نمی‌کند.

## انتشار نسخه جدید
1. فایل‌های نسخه جدید را در همان مخزن جایگزین کن و `commit` انجام بده.
2. پس از موفقیت workflow، همان لینک GitHub Pages را برای مشتری بفرست.
3. بازکردن لینک در حالت آنلاین نسخه جدید را دریافت می‌کند. اگر برنامه از قبل باز باشد، بنر `نسخه جدید AZA آماده است` برای بارگذاری مجدد نمایش داده می‌شود.
4. داده‌های فروشگاه در پایگاه داده محلی جدا از فایل‌های برنامه هستند؛ با این حال تغییر ساختار داده‌ها در نسخه‌های بعدی باید با مهاجرت سازگار انجام شود.

## محدودیت مبنای نسخه
این بسته بر اساس آخرین فایل HTML قابل خواندن در آرشیو فعلی ساخته شده است. ZIP اندرویدی مورخ ۱۴ اکتبر در آرشیو قابل استخراج نبود؛ بنابراین این بسته را نباید بدون مقایسه، نسخه دقیق همان ZIP دانست.

## آزمون پیش از استفاده واقعی
با داده آزمایشی، ثبت کالا و فاکتور، بستن و بازکردن برنامه، حالت پرواز، پشتیبان‌گیری و بازیابی را امتحان کن. تا پیش از موفقیت آزمون‌ها با اطلاعات واقعی فروشگاه کار نکن.

## قابلیت‌های اضافه‌شده در نسخه جدید
- در بخش «فروش جدید»، دکمه «اسکن بارکد» دوربین پشت گوشی را باز می‌کند و در مرورگرهای سازگار بارکد کالا را می‌خواند و همان کالا را به سبد فروش اضافه می‌کند. برای اسکن خودکار، سایت باید با HTTPS باز شود و اجازه دوربین داده شده باشد. اگر مرورگر اسکن خودکار را پشتیبانی نکند، امکان وارد کردن شماره بارکد به‌صورت دستی در همان پنجره وجود دارد.
- خروجی تصویری فاکتور مرتب شده است: نام و مشخصات کالا سمت راست، مبلغ سمت چپ و جمع‌ها به‌صورت ردیفی نمایش داده می‌شوند.


اصلاحات نسخه ۶:
- نام برنامه فقط «AZA» است.
- هر لیبل چاپی بارکد متفاوت و قابل‌اسکن خودش را دارد؛ برای بارکد عددی، شماره‌گذاری افزایشی انجام می‌شود.
- فاکتور خروجی با محتوای نزدیک‌تر به مرکز، سربرگ فروشگاه، شماره/تاریخ/ساعت مرتب و ردیف‌های منظم بازطراحی شده است.
- مبلغ دریافتی به‌صورت پیش‌فرض با مبلغ قابل پرداخت محاسبه می‌شود و پس از تخفیف به‌روزرسانی می‌شود؛ در صورت نیاز همچنان می‌توان مبلغ دریافتی را دستی تغییر داد.
- متن گزینه ورود کوتاه‌تر شده است: «ذخیره نام کاربری و رمز عبور».


## اصلاح نسخه ۶
- چاپ فاکتور از همان HTML و CSS پیش‌نمایش استفاده می‌کند تا طراحی در چاپ و ذخیره PDF یکسان بماند.
- ذخیره تصویر و اشتراک‌گذاری نیز از همان محتوای پیش‌نمایش و استایل فاکتور ساخته می‌شود؛ در مرورگرهایی که رندر HTML داخل تصویر را پشتیبانی نکنند، از چاپ و ذخیره PDF استفاده کن.


## اصلاحات نسخه ۶
- تصاویر پیش‌فرض دسته‌بندی برای کیف، کفش، تیشرت، شورت، زیرپیراهن، عطر، ساعت، جوراب، پیراهن، کت‌وشلوار، هودی، کت تک، شلوار، انگشتر و کمربند. اگر برای کالا عکس واقعی بارگذاری شود، عکس خود کالا اولویت دارد؛ تصاویر دسته‌بندی نیز برای حالت آفلاین در بسته قرار دارند.
- تراز و یکسان‌سازی ارتفاع دکمه اسکن بارکد و کادر ورود دستی بارکد.


در نسخه ۱۵: دکمه انتخاب تعداد ستون‌های داشبورد حذف شده و موجودی کالا همیشه پنج‌تایی نمایش داده می‌شود. ذخیره مخاطب از طریق فایل vCard با پسوند VCF انجام می‌شود؛ فایل دانلودشده را از اعلان دانلودها یا پوشه Downloads باز کنید و در مخاطبین ذخیره کنید.
