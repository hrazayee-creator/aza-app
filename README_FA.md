# AZA — نسخه ۲۶

برنامه PWA مدیریت فروشگاه لباس و کفش، با رابط کاربری سازگار با موبایل، کار آفلاین و پشتیبان‌گیری خودکار محلی.

## تغییرات نسخه ۲۵
- کوتاه‌شدن متن تبلیغاتی صفحه ورود به «فروش و موجودی، همه یک‌جا.»
- تبدیل فهرست کالاهای لیبل‌دار به بخش کشویی برای خلوت‌ترشدن صفحه لیبل.
- این تغییرات فقط رابط کاربری را تغییر می‌دهند؛ پایگاه داده و اطلاعات قبلی حذف یا بازنشانی نمی‌شوند.
- افزودن معرفی تبلیغاتی کوتاه به صفحه ورود، شماره پشتیبانی 09372301428 و اعتبار طراحی و توسعه برای آزادمنش.
- افزودن پشتیبان خودکار محلی در هر ورود موفق؛ حداکثر ۱۰ نسخه اخیر در IndexedDB همین دستگاه/مرورگر نگهداری می‌شود.
- افزودن امکان بازیابی آخرین پشتیبان خودکار محلی، در کنار دانلود فایل JSON و بازیابی از فایل.
- جمع‌شدن بخش‌های تنظیمات به صورت کشویی برای کاهش شلوغی صفحه.
- ارتقای نسخه دیتابیس IndexedDB با افزودن مخزن پشتیبان، بدون حذف مخزن داده‌های فعلی.
- یکپارچه‌سازی نسخه رابط و کش Service Worker روی نسخه ۲۵.

## نکته مهم درباره پشتیبان خودکار
پشتیبان خودکار در فضای ذخیره‌سازی محلی همان مرورگر ذخیره می‌شود؛ این کار به‌تنهایی فایل جداگانه‌ای در پوشه Downloads گوشی ایجاد نمی‌کند، چون مرورگرها معمولاً اجازه ذخیره فایل بی‌صدا در فایل‌سیستم را نمی‌دهند. پاک‌کردن داده‌های سایت، حذف پروفایل مرورگر یا خرابی دستگاه می‌تواند پشتیبان محلی را از بین ببرد. برای حفاظت واقعی، از بخش تنظیمات فایل JSON دانلود و در فضای ابری یا دستگاه دیگری نگهداری کنید.

## حفظ اطلاعات هنگام انتشار نسخه جدید
داده‌های اصلی در IndexedDB با نام ثابت `aza_mobile_local_db` و کلید `main` ذخیره می‌شوند. تغییر نسخه رابط و کش Service Worker به‌خودی‌خود این داده‌ها را حذف نمی‌کند. در مهاجرت‌های دیتابیس آینده، مخزن‌های قبلی نباید حذف یا پاک‌سازی شوند. با این حال، پیش از هر انتشار جدید حتماً فایل پشتیبان جداگانه تهیه و نسخه جدید را با یک کپی آزمایشی از داده‌ها بررسی کنید.

## نصب روی GitHub Pages
محتویات ZIP را در ریشه مخزن بارگذاری کنید؛ پوشه‌های `.github` و `icons` را حفظ کنید. سپس لینک GitHub Pages را با Chrome باز کنید و در صورت نمایش پیام به‌روزرسانی، نسخه جدید را بارگذاری کنید.

## نکات امنیتی
این نسخه برای استفاده محلی/پیش‌نمایش طراحی شده است. ورود سمت کاربر به‌تنهایی حفاظت امنیتی واقعی ایجاد نمی‌کند و اطلاعات ورود در ساختار فعلی به‌صورت امن سمت سرور اعتبارسنجی نمی‌شوند. پشتیبان محلی نیز رمزنگاری نشده است. برای استفاده تجاری جدی یا چنددستگاهی، احراز هویت سمت سرور، مجوزدهی و پشتیبان‌گیری مستقل لازم است.

**طراحی و توسعه:** آزادمنش


## تغییرات نسخه ۲۶
- افزودن فعال‌سازی ورود با احراز هویت دستگاه (اثر انگشت/قفل صفحه) از صفحه ورود؛ برای فعال‌سازی باید یک‌بار نام کاربری و رمز فعلی وارد شود.
- افزودن درخواست مجوز Persistent Storage پس از ورود برای کاهش احتمال پاک‌شدن خودکار داده‌ها توسط مرورگر؛ پذیرش این درخواست در اختیار مرورگر است.
- اصلاح Service Worker تا نبودن تصاویر اختیاری باعث شکست نصب/به‌روزرسانی کش برنامه نشود.

## محدودیت مهم ورود زیست‌سنجی
این برنامه یک PWA محلی و بدون سرور احراز هویت است. قابلیت جدید از WebAuthn و احراز هویت خود دستگاه استفاده می‌کند تا ورود راحت‌تر شود، اما چون سرور مستقلی برای اعتبارسنجی امضای WebAuthn وجود ندارد، آن را نباید جایگزین امنیت سمت سرور یا حفاظت کامل در برابر دستکاری محلی دانست. بسته به گوشی، مرورگر ممکن است اثر انگشت، تشخیص چهره یا PIN/قفل صفحه را نمایش دهد.

## نگهداری اطلاعات
درخواست Persistent Storage تضمین مطلق نیست و مرورگر ممکن است آن را نپذیرد. پاک‌کردن داده‌های سایت، حذف برنامه/پروفایل مرورگر یا خرابی گوشی همچنان می‌تواند اطلاعات محلی را از بین ببرد. فایل JSON پشتیبان را به‌صورت دوره‌ای در محل دیگری نگهداری کن.
