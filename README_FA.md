# AZA — نسخه ۲۱

این نسخه بر پایه نسخه ۲۰ ساخته شده و فقط صفحه اسکن بارکد اصلاح شده است:

- خواندن بارکد با موتور چندفرمتی ZXing و استفاده از BarcodeDetector گوشی به‌عنوان جایگزین.
- حذف کادر ورود دستی بارکد و دکمه جست‌وجوی غیرضروری از پنجره دوربین؛ اسکن باید خودکار انجام شود.
- پس از شناسایی بارکد، کالای متناظر به سبد فروش اضافه می‌شود؛ اگر بارکد در کالاهای ثبت‌شده وجود نداشته باشد، پیام واضح نمایش داده می‌شود.
- نام کش برنامه به نسخه ۲۱ تغییر یافته است تا مرورگر نسخه جدید را دریافت کند.

برای اسکن با ZXing اتصال اینترنت لازم است تا کتابخانه اسکنر از CDN بارگذاری شود؛ اگر بارگذاری نشود، برنامه از BarcodeDetector داخلی مرورگر استفاده می‌کند، در صورتی که پشتیبانی شود.

## نصب روی GitHub Pages
فایل ZIP را استخراج و تمام محتویات آن را در ریشه مخزن بارگذاری کنید. پوشه `.github` و پوشه `icons` را حفظ کنید و خود فایل ZIP را مستقیماً در مخزن قرار ندهید. سپس همان لینک GitHub Pages را در Chrome باز کنید.
